# VK-бот рассылок «Чудо леса»

Бот собирает добровольные подписки в сообщениях сообщества VK и отправляет
рассылки только активным подписчикам.

## Возможности

- подписка и отписка кнопками;
- хранение подписчиков в SQLite;
- черновик и обязательное подтверждение перед рассылкой;
- рассылка текста и вложений из сообщения администратора;
- статистика подписчиков и отчёт о доставке;
- секретные данные берутся только из переменных окружения.

## Подключение к BotHost

В BotHost добавьте:

| Имя | Значение |
| --- | --- |
| `VK_TOKEN` | секретный ключ доступа сообщества |
| `GROUP_ID` | числовой ID сообщества без знака минус |
| `ADMIN_IDS` | числовой ID администратора; несколько ID через запятую |
| `DATA_DIR` | папка базы, обычно `data` |

Никогда не добавляйте `VK_TOKEN` в файлы GitHub.

В качестве главного файла укажите `main.py`, ветка репозитория — `main`.

## Команды пользователя

- `Подписаться`
- `Отписаться`
- `Помощь`

## Команды администратора

- `/рассылка Текст` — создать черновик; к сообщению можно приложить фото;
- `/отправить` — подтвердить и запустить рассылку;
- `/отмена` — удалить черновик;
- `/статистика` — количество подписчиков;
- `/помощь` — показать подсказку.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

BotHost должен запускать `main.py`. В сообществе необходимо включить сообщения,
Bots Long Poll API и событие «Входящее сообщение».
