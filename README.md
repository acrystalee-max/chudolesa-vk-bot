# VK-бот рассылок «Чудо леса»

Бот собирает добровольные подписки в сообщениях сообщества VK и отправляет
рассылки только активным подписчикам.

## Возможности

- отдельные кнопки для запуска, подписки и отписки;
- приветственный подарок: скидка 5% на первый заказ;
- хранение подписчиков в SQLite;
- черновик и обязательное подтверждение перед рассылкой;
- рассылка текста и вложений из сообщения администратора;
- статистика подписчиков и отчёт о доставке;
- секретные данные берутся только из переменных окружения.

## Подключение к BotHost

В BotHost добавьте:

| Имя | Значение |
| --- | --- |
| `VK_TOKEN` | секретный ключ, если BotHost не передал его автоматически |
| `GROUP_ID` | необязательно; бот сам определит сообщество `chudolesa` |
| `ADMIN_IDS` | числовой ID администратора; можно добавить после первого запуска |
| `DATA_DIR` | папка базы, обычно `data` |
| `WELCOME_DISCOUNT_PERCENT` | необязательно; размер приветственной скидки, по умолчанию `5` |
| `WELCOME_PROMO_CODE` | необязательно; промокод, по умолчанию `ПОДАРОК` |

Никогда не добавляйте `VK_TOKEN` в файлы GitHub.

Чтобы узнать свой ID после первого запуска, отправьте боту `/мойid`, затем
добавьте полученное число в `ADMIN_IDS` и перезапустите бота.

В качестве главного файла укажите `main.py`, ветка репозитория — `main`.

## Команды пользователя

- `Подписаться`
- `Отписаться`
- `Помощь`

## Команды администратора

- `/рассылка` — бот попросит следующим сообщением прислать текст или фото;
- `/рассылка Текст` — также можно сразу создать черновик одной командой;
- `/отправить` — подтвердить и запустить рассылку;
- `/отмена` — удалить черновик;
- `/статистика` — количество подписчиков;
- `/помощь` — показать подсказку.

### Как отправить рассылку

1. Отправьте боту `/рассылка`.
2. Следующим сообщением пришлите текст и при необходимости фотографию.
3. Проверьте черновик и нажмите `/отправить`.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

BotHost должен запускать `main.py`. В сообществе необходимо включить сообщения,
Bots Long Poll API и событие «Входящее сообщение». В разделе «Сообщения» →
«Настройки для бота» включите «Возможности ботов» и «Добавить кнопку “Начать”».
